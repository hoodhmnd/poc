Proof of concept: mail-designer message bus accepts cross-origin messages

Authorized security testing against a Bugcrowd program. This page demonstrates that app.web.com's mail designer dispatches window.message events without checking event.origin.

What happens when you press the button. This page opens the Web.com mail designer in a popup and posts one message to it. If you are signed in to app.web.com, that message becomes executing HTML in the app.web.com origin, reads your document.cookie including the cp_token session cookie, and sends it to the collector URL shown below. Only press it with a test account you own.
